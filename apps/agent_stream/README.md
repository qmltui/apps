# Agent Stream (`agent_stream`)

Interactive coding-agent session combining `Terminal.Inline`, `Scrollback`, slash-command autocomplete, model selection, permission prompts, and a modal diff inspector.

```sh
./build/apps/agent_stream/qmltui_agent_stream
```

`BannerCard` defaults to a 5-row `Canvas.HalfBlock` logo (`Circle` and `Polygon` shapes); set `logoRenderMode: Canvas.Braille` for the Braille variant.
