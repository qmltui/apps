# 2048 Terminal Edition (`twozero48`)

2048 sliding-tile puzzle game with responsive tile sizing, `Behavior` color transitions, score tracking, win/keep-playing and game-over modal overlays, and WebAssembly support (`qmltui_wasm_app()`).

```sh
./build/apps/twozero48/qmltui_twozero48
```

## Controls

| Key | Action |
| :--- | :--- |
| `Arrows` / `W` `A` `S` `D` / `H` `J` `K` `L` | Slide and merge tiles |
| `C` / `Esc` (on 2048 Win overlay) | Continue playing past 2048 |
| `R` / `Enter` (on Game Over) | Reset board |
| `Q` / `Esc` | Quit |
