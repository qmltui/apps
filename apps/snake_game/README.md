# Terminal Snake (`snake_game`)

Classic arcade Snake rendered with `Canvas.HalfBlock` subpixels (1×2 per cell), dynamic speed levels, score tracking, pause overlay, responsive viewport sizing, and WebAssembly support (`qmltui_wasm_app()`).

```sh
./build/apps/snake_game/qmltui_snake_game
```

## Controls

| Key | Action |
| :--- | :--- |
| `Arrows` / `W` `A` `S` `D` / `H` `J` `K` `L` | Steer snake |
| `Space` / `P` | Pause or resume game |
| `R` / `Enter` (on Game Over) | Restart game |
| `Q` / `Esc` | Quit |
